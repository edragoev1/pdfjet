# PDFjet for .NET

PDFjet is a PDF library with no dependencies on external packages. This site
documents the C# port: every class is in the `PDFjet.NET` namespace.

Start with the [API reference](xref:PDFjet.NET). The `examples` directory in
the [repository](https://github.com/edragoev1/pdfjet) has 50 complete programs.
