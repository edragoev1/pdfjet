PDFjet Java Examples

Each example links to its source code and to the PDF file it creates. To create the PDF files yourself, run the build-java.cmd or build-java.sh script.

  1. Example_01.java  Example_01.pdf   Drawing English, Greek and Bulgarian text in TextBlock components with borders, rounded corners and highlighted keywords, in a PDF/UA document.
  2. Example_02.java  Example_02.pdf   Drawing Simplified and Traditional Chinese text with the embedded IBM Plex Sans SC and TC fonts, in a PDF/UA document.
  3. Example_03.java  Example_03.pdf   Drawing Japanese and Korean text with the embedded IBM Plex Sans JP and KR fonts, in a PDF/UA document.
  4. Example_04.java  Example_04.pdf   Drawing Arabic, Hebrew, Persian and Thai text, including right to left text blocks, in a PDF/UA document.
  5. Example_05.java  Example_05.pdf   Fonts that are not embedded: the core fonts, Helvetica, Times and Courier, and Chinese, Japanese and Korean in the Adobe CJK fonts, which keep a document very small, a few kilobytes, and what they cost: the viewer supplies them, so the text does not look the same everywhere, and the document cannot be PDF/A or PDF/UA.
  6. Example_06.java  Example_06.pdf   Embedded fonts: the same words in five weights of IBM Plex Sans, and why embedded fonts are better than the core fonts, in a PDF/UA document.
  7. Example_07.java  Example_07.pdf   Reading fonts from .otf and .ttf files: any OpenType or TrueType file on the computer is a font for PDFjet, and a TrueType font is embedded as a subset of the glyphs a document draws.
  8. Example_08.java  Example_08.pdf   The location, ascent, descent and end point of text drawn with the TextBlock component.
  9. Example_09.java  Example_09.pdf   Drawing chemical formulas with CompositeTextLine: the digits of a formula are subscripts, the charge of an ion and the mass number of an isotope are superscripts, and each formula is one structure element of the tagged document.
  10. Example_10.java  Example_10.pdf   Using the TextBlock component with a fixed height, a background color, a border, highlighted keywords and transparency, in a PDF/UA document.
