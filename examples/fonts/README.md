# Fonts of the examples

Fonts that only the examples use, not packaged with PDFjet:

- `NotoSansDevanagari/NotoSansDevanagari-Regular.ttf`, Noto Sans Devanagari
  2.001, and `NotoSansKhmer/NotoSansKhmer-Regular.ttf`, Noto Sans Khmer 2.001,
  for Example_52: Hindi and Khmer shaped by java.awt.font and drawn with
  Page.drawGlyphs. Both under the SIL Open Font License 1.1 (license.txt
  beside each).
