PDFjet C# Examples

Each example links to its source code and to the PDF file it creates. The linked PDF files are created by the Java examples, which produce the same documents. To create the PDF files with the C# examples, run the build-dotnet.cmd or build-dotnet.sh script.

  1. Example_01.cs  Example_01.pdf   Drawing English, Greek and Bulgarian text in TextBlock components with borders, rounded corners and highlighted keywords, in a PDF/UA document.
  2. Example_02.cs  Example_02.pdf   Drawing Japanese, Korean, Simplified Chinese and Traditional Chinese text with embedded IBM Plex Sans fonts.
  3. Example_03.cs  Example_03.pdf   Using the Text and Paragraph components: paragraphs that mix fonts and colors, numbered paragraphs and highlighted keywords.
  4. Example_04.cs  Example_04.pdf   Drawing Chinese, Japanese and Korean text with CJK fonts that are not embedded in the PDF.
  5. Example_05.cs  Example_05.pdf   Text kerning, rotated text, and drawing circles, arcs and ellipses.
  6. Example_06.cs  Example_06.pdf   Embedding file attachments in PDF, and adding text, polygon, square and circle annotations.
  7. Example_07.cs  Example_07.pdf   Adding a watermark to the pages of a PDF/A-3B document.
  8. Example_08.cs  Example_08.pdf   Using the Table component to draw a CSV file on several pages, with an image and a barcode in its cells and a "Page X of N" footer.
  9. Example_09.cs  Example_09.pdf   Using the Chart component to draw a scatter chart with a trend line, and a table that lists the chart points.
  10. Example_10.cs  Example_10.pdf   Using the TextColumn component to draw centered and justified paragraphs.
  11. Example_11.cs  Example_11.pdf   Using Code 128, Code 39, UPC-A and EAN-13 linear barcodes, drawn in different directions.

  13. Example_13.cs  Example_13.pdf   Drawing a table with two header rows, merged header cells and cell background colors.

  15. Example_15.cs  Example_15.pdf   Using the CompositeTextLine together with the Table class to draw the H2O formula in the cells of a PDF/UA table.
  16. Example_16.cs  Example_16.pdf   Using the TextBox component with a background color, borders, highlighted keywords and transparency, in a PDF/UA document.
  17. Example_17.cs  Example_17.pdf   Test case for PNG images: palette, grayscale and color images from PngSuite with different bit depths, filter types, compression levels and transparency.

  19. Example_19.cs  Example_19.pdf   Using the TextBox component to draw text next to images.
