# PDFjet for Swift

> PDFjet creates PDF documents from Swift 6.1 or later, on macOS, iOS and Linux. One package, no dependencies, and none of Apple's frameworks, so it runs on a Swift server too: text and tables that flow across pages, embedded fonts for the world's languages, charts, barcodes, images and SVG, Markdown, accessible PDF/UA and archival PDF/A documents, encryption, and adding to existing PDFs. It writes each page to the output stream as it goes, so long documents need little memory. This file is for AI coding assistants: the rules below are where code written without reading the examples goes wrong.

## Install

In the `Package.swift` of your package:

```swift
dependencies: [
    .package(url: "https://github.com/edragoev1/pdfjet-swift", from: "9.1.9"),
],
targets: [
    .executableTarget(name: "App", dependencies: [
        .product(name: "PDFjet", package: "pdfjet-swift"),
    ]),
]
```

In Xcode: File > Add Package Dependencies, with the URL https://github.com/edragoev1/pdfjet.git. For Chinese, Japanese, Korean, Arabic, Hebrew and Thai, add the product `PDFjetFontsWorld` of the same package too (52 MB of fonts in the app; no code needed).

```swift
import Foundation
import PDFjet
```

## Rules

1. **End every document with `try pdf.complete()`.** It writes the end of the file and closes the stream. A PDF without it is broken.
2. **Coordinates are points (1/72 inch) from the top-left corner of the page; y grows downward,** not upward as in Core Graphics. `Letter.PORTRAIT` is 612 x 792, `A4.PORTRAIT` 595 x 842. A margin of 50 leaves a width of 512 on Letter. Coordinates and sizes are `Float`: convert a `Double` or a `CGFloat` with `Float(x)`.
3. **Create, set, place, draw:** make a component, set it up, then `setLocation(x, y)` and `drawOn(page)`. Arguments have no labels: `TextLine(font, "text")`. Setters return the object, so calls chain, and their results may be left unused. Most `drawOn` methods return `[Float]`, `[x, y]` where the component ended: place the next one below it, `y = block.drawOn(page)[1] + 12.0`.
4. **Pages:** `Page(pdf, Letter.PORTRAIT)` makes a page and adds it to the document at once. For content longer than one page, let the component make the pages: `table.drawOn(pdf, &pages, Letter.PORTRAIT)` (also `try markdown.drawOn(pdf, text, &pages, Letter.PORTRAIT)`) fills a `var pages = [Page]()` you pass with `&`, with as many as it needs. **Those pages are not in the document yet: add them with `pdf.addPages(pages)`** after drawing on them, for example after adding footers such as "Page 3 of 7" with `page.addFooter(textLine)`. Give the table a bottom margin, `table.setBottomMargin(50.0)`, so that its last row on each page stays clear of the footer. Forgetting it gives "A PDF needs at least one page" or a document without them.
5. **Fonts:** `try Font(pdf, IBMPlexSans.Regular)` loads a font PDFjet carries, in the bundle of the product `PDFjet`; the constants are `IBMPlexSans`, `IBMPlexSerif`, `CascadiaMono` (monospace), and, with the product `PDFjetFontsWorld`, `IBMPlexSansJP`, `KR`, `SC`, `TC`, `Arabic`, `Hebrew`, `Thai`, and Noto Sans of the scripts PDFjet draws as outlines, `NotoSansDevanagari`, `NotoSansBengali`, `NotoSansGurmukhi`, `NotoSansGujarati`, `NotoSansOriya`, `NotoSansTamil`, `NotoSansTelugu`, `NotoSansKannada`, `NotoSansMalayalam`, `NotoSansSinhala`, `NotoSansKhmer`, `NotoSansLao` and `NotoSansMyanmar` (Regular and Bold), for text such as Hindi in a `TextBlock` or a `TextLine`: `TextBlock(hindi, text).setFallbackFont(latin).setLanguage("hi").setWidth(w).setLocation(x, y).drawOn(page)`, as for any text. A paragraph in one of these scripts is shaped by Core Text on Apple platforms and drawn as outlines, tagged with its text; the other paragraphs of the block are drawn as text. On Linux, give the block `.setShaper(HBShape())`, or `TextBlock.setDefaultShaper(HBShape())` for every block and line, which runs HarfBuzz's program `hb-shape` (installed with `apt install libharfbuzz-bin` or `brew install harfbuzz`). A TextBlock does not flow from page to page: draw a TextBlock a paragraph, measured first with `drawOn(nil)`, which returns its corner, and start a new page when it would end below the margin. In a TextBlock, a paragraph whose first letter is Arabic or Hebrew (Persian, Urdu) is right to left by itself, aligned to the right; `setRightToLeft` sets the whole block. PDFjet works with any TrueType (.ttf) or OpenType (.otf) font file: `try Font(pdf, "/path/to/MyFont.otf")`, or a font in your app's bundle by its path, `Bundle.main.path(forResource:ofType:)`. Prefer the fonts PDFjet carries; for a script they lack, use a font whose license allows embedding, such as Noto from Google Fonts, from the `static` folder of its download: a variable font is drawn in its default weight only, so make each weight a file of its own with fontTools (`fonttools varLib.instancer Font[wght].ttf wght=700 -o Font-Bold.ttf`). Fonts are embedded as a subset of the characters drawn. Set the size on the font (`font.setSize(11.0)`) or on the component (`setFontSize`). Do not use `CoreFont` (Helvetica, Times, Courier) for real documents: they draw only Western European characters, look different in each viewer, and are not allowed in PDF/UA or PDF/A. PDFjet does not use the fonts of the system or UIFont and NSFont.
6. **Colors are `Int32` RGB values:** `0x1F4E79`, or a constant of `Color` such as `Color.navy`.
7. **Accessible documents:** `pdf.setCompliance(Compliance.PDF_UA_1)` and `pdf.setTitle(...)` right after `PDF(...)`; give headings `setStructureType(StructElem.H1)` (H2, …) and every image `setAltDescription("...")`. Archival: `Compliance.PDF_A_1B`, `PDF_A_2B`, `PDF_A_3B`; `Compliance.PDF_A_3A_UA_1` is archival and accessible.
8. **The output stream:** `PDF(OutputStream(toFileAtPath: "out.pdf", append: false)!)`, or any `OutputStream`, not opened: `PDF` opens it and `complete()` closes it; `complete(closeStream: false)` flushes it and leaves it open. In memory: `let stream = OutputStream(toMemory: ())`, and after `complete()`, `stream.property(forKey: .dataWrittenToMemoryStreamKey) as? Data`. On iOS write to the app's documents or temporary folder, not to the working directory.
9. **Errors, and `try`:** the calls that read a file or a stream, and a few that check their input, throw an error that says what is wrong, most often a `PDFjetError` with its `message`, and need `try`: `Font(...)`, `Image(...)`, `SVGImage(...)`, `Content.ofTextFile(...)`, `Barcode(...)`, `Markdown.drawOn`, `pdf.read(from:)` and `pdf.complete()`. A mistake in the calling code, a bad value or a call at the wrong time, is recorded rather than thrown, and the document goes on without what it would have broken; `complete()` then throws it and writes no broken PDF. So never `try?` the `complete()`. Read the message.

## A page of text

```swift
import Foundation
import PDFjet

let pdf = PDF(OutputStream(toFileAtPath: "Hello.pdf", append: false)!)
pdf.setCompliance(Compliance.PDF_UA_1)
pdf.setTitle("Hello")

let bold = try Font(pdf, IBMPlexSans.SemiBold)
bold.setSize(20.0)
let regular = try Font(pdf, IBMPlexSans.Regular)
regular.setSize(11.0)

let page = Page(pdf, Letter.PORTRAIT)
let title = TextLine(bold, "Hello")
title.setStructureType(StructElem.H1)
title.setLocation(50.0, 70.0)
title.drawOn(page)

let text = TextBlock(regular,
        "TextBlock wraps text to its width. Its drawOn returns where the text ended.")
text.setLocation(50.0, 90.0)
text.setWidth(512.0)
let y = text.drawOn(page)[1]

TextLine(regular, "This line is placed below the block.")
        .setLocation(50.0, y + 20.0).drawOn(page)

try pdf.complete()
```

## A table over as many pages as it needs

```swift
import Foundation
import PDFjet

let pdf = PDF(OutputStream(toFileAtPath: "Report.pdf", append: false)!)
pdf.setCompliance(Compliance.PDF_UA_1)
pdf.setTitle("Report")
let bold = try Font(pdf, IBMPlexSans.SemiBold)
let regular = try Font(pdf, IBMPlexSans.Regular)

var data = [[Cell]]()
data.append([
    Cell(bold, "Item").setBackgroundColor(0xF1F3F6),
    Cell(bold, "Quantity").setBackgroundColor(0xF1F3F6),
])
for i in 1...200 {
    data.append([Cell(regular, "Item \(i)"), Cell(regular, String(i * 3))])
}

let table = Table()
table.setTableData(data, 1)         // 1 header row, repeated on every page
table.setColumnWidth(0, 362.0)
table.setColumnWidth(1, 150.0)
table.rightAlignNumbers()
table.setLocation(50.0, 50.0)
table.setBottomMargin(50.0)         // room for the footer on each page

var pages = [Page]()
table.drawOn(pdf, &pages, Letter.PORTRAIT)
for (i, page) in pages.enumerated() {
    page.addFooter(TextLine(regular, "Page \(i + 1) of \(pages.count)"))
}
pdf.addPages(pages)                 // the pages the table made, into the document
try pdf.complete()
```

For tables of thousands of pages read from a file or a database, use `BigTable`: it writes each page as it fills, so its memory stays flat, with "Page i of N" footers (Example_24). `setWrapText(true)` wraps long fields within their columns, each row as tall as its tallest field (Example_51); `setFallbackFonts(header, rows)` draws characters the table's fonts lack, such as Chinese in a Latin table.

A `BigTable` takes the look of a `Table`, so that either can take the place of the other: `setColumnWidths(...)` with the widths of the cells in points, `setBorderColor(Color.black)`, `setShadingColor(Color.transparent)`, `setPadding(2)` and `setVerticalPadding(2)`, the cells' padding, and `setFooter(nil, nil)`. A `BigTable` right-aligns numbers, as `rightAlignNumbers()` does; `setTextAlignment(column, Alignment.LEFT)` aligns a column left, as a `Table` does by default. For rules under the rows alone, as cells with a bottom border, `setVerticalLines(false)` and `setTopLine(false)`, with `setHeaderColor(...)` for a shaded header.

## Markdown

```swift
let markdown = Markdown(regular, bold, italic, boldItalic, code)    // five Fonts
var pages = [Page]()
try markdown.drawOn(pdf, markdownText, &pages, Letter.PORTRAIT)
pdf.addPages(pages)
```

Headings, lists, tables, quotes, code and links, tagged in a PDF/UA document (Example_19). `try Content.ofTextFile(path)` reads a text file into a string.

## The main classes

- Document: `PDF`, `Page`, `Letter` / `A4` / `Legal` page sizes, `Compliance`, `Font`
- Text: `TextLine` (one line), `TextBlock` (wrapped to a width), `TextColumn` (justified paragraphs), `TextFrame` and `Paragraph` (text flowing across columns and pages), `CompositeTextLine` (subscripts, superscripts), `Markdown`
- Tables: `Table`, `Cell`, `BigTable`
- Graphics: `Line`, `Rect`, `Path`, `Point`, `Stamp` (drawn once, placed on every page), `Container`, `GraphicsState` (transparency)
- Images: `Image` (PNG, JPEG, BMP), `SVGImage` (drawn as vectors)
- Charts: `SimpleBarChart`, `SimpleLineChart`, `SimpleScatterChart`, `DonutChart`
- Barcodes: `Barcode` (Code 128, Code 39, UPC-A, EAN-13; its initializer throws), `QRCode`, `DataMatrix`, `PDF417`
- Interactive: links and destinations, `Bookmark`, file attachments, `CheckBox`, `RadioButton`, `Form` and `Field`
- Existing PDFs: `try pdf.read(from: inputStream)` opens one; then stamp, fill, merge and split (Examples 48 to 50)
