# PDFjet for .NET

> PDFjet creates PDF documents from C# and the other .NET languages, on .NET 8 or later and .NET Framework 4.8. One library, no dependencies: text and tables that flow across pages, embedded fonts for the world's languages, charts, barcodes, images and SVG, Markdown, accessible PDF/UA and archival PDF/A documents, encryption, and adding to existing PDFs. It writes each page to the output stream as it goes, so long documents need little memory. This file is for AI coding assistants: the rules below are where code written without reading the examples goes wrong.

## Install

```bash
dotnet add package PDFjet --version 9.1.9
```

Or in the project file: `<PackageReference Include="PDFjet" Version="9.1.9" />`. For Chinese, Japanese, Korean, Arabic, Hebrew and Thai, add the package `PDFjet.Fonts.World` of the same version.

```csharp
using System.Collections.Generic;
using System.IO;
using PDFjet.NET;
```

Every class is in the one namespace `PDFjet.NET`, the fonts and the barcodes too.

## Rules

1. **End every document with `pdf.Complete()`.** It writes the end of the file and closes the stream. A PDF without it is broken.
2. **Coordinates are points (1/72 inch) from the top-left corner of the page; y grows downward.** `Letter.PORTRAIT` is 612 x 792, `A4.PORTRAIT` 595 x 842. A margin of 50 leaves a width of 512 on Letter. Coordinates and sizes are `float`, with no `double` overloads: write `50f`, and cast a `double` with `(float)`.
3. **Create, set, place, draw:** make a component, set it up, then `SetLocation(x, y)` and `DrawOn(page)`. Setters return the object, so calls chain. Most `DrawOn` methods return `float[] {x, y}` where the component ended: place the next one below it, `y = block.DrawOn(page)[1] + 12f;`.
4. **Pages:** `new Page(pdf, Letter.PORTRAIT)` makes a page and adds it to the document at once. For content longer than one page, let the component make the pages: `table.DrawOn(pdf, pages, Letter.PORTRAIT)` (also `Markdown`) fills a `List<Page>` you pass in, as many as it needs. **Those pages are not in the document yet: add them with `pdf.AddPages(pages)`** after drawing on them, for example after adding footers such as "Page 3 of 7" with `page.AddFooter(textLine)`. Give the table a bottom margin, `table.SetBottomMargin(50f)`, so that its last row on each page stays clear of the footer. Forgetting it gives "A PDF needs at least one page" or a document without them.
5. **Fonts:** `new Font(pdf, IBMPlexSans.Regular)` loads a font PDFjet carries; the font classes are `IBMPlexSans`, `IBMPlexSerif`, `CascadiaMono` (monospace), and, with the package `PDFjet.Fonts.World`, `IBMPlexSansJP`, `KR`, `SC`, `TC`, `Arabic`, `Hebrew`, `Thai`, and Noto Sans of the scripts `ComplexText` draws, `NotoSansDevanagari`, `NotoSansBengali`, `NotoSansGurmukhi`, `NotoSansGujarati`, `NotoSansOriya`, `NotoSansTamil`, `NotoSansTelugu`, `NotoSansKannada`, `NotoSansMalayalam`, `NotoSansSinhala`, `NotoSansKhmer`, `NotoSansLao` and `NotoSansMyanmar` (Regular and Bold), which are only for `ComplexText` (`new ComplexText(hindi, text).SetFallbackFont(latin).SetLanguage("hi").SetShaper(shaper).SetLocation(x, y).SetWidth(w).DrawOn(page)`, where, without `SetShaper`, `HBShape` runs HarfBuzz's program `hb-shape` (installed with `apt install libharfbuzz-bin`, `brew install harfbuzz`, or HarfBuzz's Windows zip), or an `IShaper` of your own, such as Example_52's `HarfBuzzShaper` with HarfBuzzSharp; PDFjet draws the glyphs as outlines; a `List<string>` of paragraphs with `SetHeight(h)` flows from page to page: `while (text.HasMoreText()) { text.SetLocation(x, y).DrawOn(new Page(pdf, Letter.PORTRAIT)); }`) (never in a TextLine or TextBlock: PDFjet does not shape Devanagari, and the letters would come out wrong). PDFjet works with any TrueType (.ttf) or OpenType (.otf) font file: `new Font(pdf, "/path/to/MyFont.otf")`. Prefer the fonts PDFjet carries; for a script they lack, use a font whose license allows embedding, such as Noto from Google Fonts, from the `static` folder of its download: a variable font is drawn in its default weight only, so make each weight a file of its own with fontTools (`fonttools varLib.instancer Font[wght].ttf wght=700 -o Font-Bold.ttf`). Fonts are embedded as a subset of the characters drawn. Set the size on the font (`font.SetSize(11f)`) or on the component (`SetFontSize`). Do not use `CoreFont` (Helvetica, Times, Courier) for real documents: they draw only Western European characters, look different in each viewer, and are not allowed in PDF/UA or PDF/A. The classes `NotoSans`, `JetBrainsMono`, `SourceSerif4`, `IBMPlexMono` and `IBMPlexMath` are obsolete: PDFjet does not carry those fonts.
6. **Colors are `int` RGB values:** `0x1F4E79`, or a constant of `Color` such as `Color.navy` (lowercase names).
7. **Accessible documents:** `pdf.SetCompliance(Compliance.PDF_UA_1)` and `pdf.SetTitle(...)` right after `new PDF(...)`; give headings `SetStructureType(StructElem.H1)` (H2, …) and every image `SetAltDescription("...")`. Archival: `Compliance.PDF_A_1B`, `PDF_A_2B`, `PDF_A_3B`; `Compliance.PDF_A_3A_UA_1` is archival and accessible.
8. **Wrap the output stream:** `new PDF(new BufferedStream(new FileStream("out.pdf", FileMode.Create)))`, or any `Stream`. `Complete()` closes it, so no `using` is needed; `pdf.Complete(true)` flushes it and leaves it open, for a `MemoryStream` you read afterwards. ASP.NET Core forbids synchronous writes to `Response.Body`, and PDFjet writes synchronously: write to a `MemoryStream` with `Complete(true)`, then set its `Position` to 0 and copy it to the response.
9. **Names that clash:** `PDFjet.NET.Path` has the name of `System.IO.Path`, which the implicit usings of a project made with `dotnet new` bring in, so `Path` alone does not compile: write `PDFjet.NET.Path`, or `using Path = PDFjet.NET.Path;`. In a project that uses `System.Drawing`, `Font`, `Color`, `Image` and `Point` clash in the same way.
10. **Errors:** a mistake in the calling code throws, an `ArgumentException` for a bad value and an `InvalidOperationException` for a call at the wrong time, with a message that says what to change, rather than writing a broken PDF. `Complete()` then refuses to finish the document, even when the exception was caught. A font file that is not there throws a `FileNotFoundException`. Read the message.

## A page of text

```csharp
public class Hello {
    public static void Main() {
        PDF pdf = new PDF(new BufferedStream(new FileStream("Hello.pdf", FileMode.Create)));
        pdf.SetCompliance(Compliance.PDF_UA_1);
        pdf.SetTitle("Hello");

        Font bold = new Font(pdf, IBMPlexSans.SemiBold);
        bold.SetSize(20f);
        Font regular = new Font(pdf, IBMPlexSans.Regular);
        regular.SetSize(11f);

        Page page = new Page(pdf, Letter.PORTRAIT);
        TextLine title = new TextLine(bold, "Hello");
        title.SetStructureType(StructElem.H1);
        title.SetLocation(50f, 70f);
        title.DrawOn(page);

        TextBlock text = new TextBlock(regular,
                "TextBlock wraps text to its width. Its DrawOn returns where the text ended.");
        text.SetLocation(50f, 90f);
        text.SetWidth(512f);
        float y = text.DrawOn(page)[1];

        new TextLine(regular, "This line is placed below the block.")
                .SetLocation(50f, y + 20f).DrawOn(page);

        pdf.Complete();
    }
}
```

## A table over as many pages as it needs

```csharp
public class Report {
    public static void Main() {
        PDF pdf = new PDF(new BufferedStream(new FileStream("Report.pdf", FileMode.Create)));
        pdf.SetCompliance(Compliance.PDF_UA_1);
        pdf.SetTitle("Report");
        Font bold = new Font(pdf, IBMPlexSans.SemiBold);
        Font regular = new Font(pdf, IBMPlexSans.Regular);

        List<List<Cell>> data = new List<List<Cell>>();
        List<Cell> header = new List<Cell>();
        header.Add(new Cell(bold, "Item").SetBackgroundColor(0xF1F3F6));
        header.Add(new Cell(bold, "Quantity").SetBackgroundColor(0xF1F3F6));
        data.Add(header);
        for (int i = 1; i <= 200; i++) {
            List<Cell> row = new List<Cell>();
            row.Add(new Cell(regular, "Item " + i));
            row.Add(new Cell(regular, (i * 3).ToString()));
            data.Add(row);
        }

        Table table = new Table();
        table.SetTableData(data, 1);        // 1 header row, repeated on every page
        table.SetColumnWidth(0, 362f);
        table.SetColumnWidth(1, 150f);
        table.RightAlignNumbers();
        table.SetLocation(50f, 50f);
        table.SetBottomMargin(50f);         // room for the footer on each page

        List<Page> pages = new List<Page>();
        table.DrawOn(pdf, pages, Letter.PORTRAIT);
        for (int i = 0; i < pages.Count; i++) {
            pages[i].AddFooter(new TextLine(regular, "Page " + (i + 1) + " of " + pages.Count));
        }
        pdf.AddPages(pages);                // the pages the table made, into the document
        pdf.Complete();
    }
}
```

For tables of thousands of pages read from a file or a database, use `BigTable`: it writes each page as it fills, so its memory stays flat, with "Page i of N" footers (Example_24). `SetWrapText(true)` wraps long fields within their columns, each row as tall as its tallest field (Example_51); `SetFallbackFonts(header, rows)` draws characters the table's fonts lack, such as Chinese in a Latin table.

A `BigTable` takes the look of a `Table`, so that either can take the place of the other: `SetColumnWidths(...)` with the widths of the cells in points, `SetBorderColor(Color.black)`, `SetShadingColor(Color.transparent)`, `SetPadding(2f)` and `SetVerticalPadding(2f)`, the cells' padding, and `SetFooter(null, null)`. A `BigTable` right-aligns numbers, as `RightAlignNumbers()` does; `SetTextAlignment(column, Alignment.LEFT)` aligns a column left, as a `Table` does by default. For rules under the rows alone, as cells with a bottom border, `SetVerticalLines(false)` and `SetTopLine(false)`, with `SetHeaderColor(...)` for a shaded header.

## Markdown

```csharp
Markdown markdown = new Markdown(regular, bold, italic, boldItalic, code);    // five Fonts
List<Page> pages = new List<Page>();
markdown.DrawOn(pdf, markdownText, pages, Letter.PORTRAIT);
pdf.AddPages(pages);
```

Headings, lists, tables, quotes, code and links, tagged in a PDF/UA document (Example_19). `Content.OfTextFile(path)` reads a text file into a string.

## The main classes

- Document: `PDF`, `Page`, `Letter` / `A4` / `Legal` page sizes, `Compliance`, `Font`
- Text: `TextLine` (one line), `TextBlock` (wrapped to a width), `TextColumn` (justified paragraphs), `TextFrame` and `Paragraph` (text flowing across columns and pages), `CompositeTextLine` (subscripts, superscripts), `Markdown`
- Tables: `Table`, `Cell`, `BigTable`
- Graphics: `Line`, `Rect`, `PDFjet.NET.Path`, `Point`, `Stamp` (drawn once, placed on every page), `Container`, `GraphicsState` (transparency)
- Images: `Image` (PNG, JPEG, BMP), `SVGImage` (drawn as vectors)
- Charts: `SimpleBarChart`, `SimpleLineChart`, `SimpleScatterChart`, `DonutChart`
- Barcodes: `Barcode` (Code 128, Code 39, UPC-A, EAN-13), `QRCode`, `DataMatrix`, `PDF417`
- Interactive: links and destinations, `Bookmark`, file attachments, `CheckBox`, `RadioButton`, `Form` and `Field`
- Existing PDFs: `new PDF(stream).Read(inputStream)` opens one; then stamp, fill, merge and split (Examples 48 to 50)
