# Introducing PDFjet

PDFjet is a library for creating PDF documents from programs. It draws text in any script, tables that break across pages, charts, barcodes and images, and it writes documents that are accessible to screen readers and fit for long-term archiving when you ask it to.

It began in 2000, when there were few PDF libraries and none that was small, fast and written in plain Java. The name says what it has been about ever since: a jet is fast and lean. PDFjet writes a 500-page document with an embedded font in under a tenth of a second, and it writes each page out and frees it as soon as the next one starts, so a long document does not need more memory than a short one.

PDFjet comes in four languages, Java, C#, Go and Swift, with the same API and the same output. Each port is written in its own language, with no native code and no dependencies: the Java library is one jar of less than half a megabyte. The four ports are checked against each other on every change: every example is built in the four languages, and the PDFs they write must draw the same text in the same fonts, sizes and positions, page by page.

## What is in the library

- Text in Latin, Greek, Cyrillic, Chinese, Japanese, Korean, Thai, Hebrew, Arabic and Persian, with right to left text, kerning and fallback fonts.
- 272 font files ready to use, from the IBM Plex, Noto, Source Serif and JetBrains Mono families, and any OpenType or TrueType file on the computer.
- Text lines, text blocks, columns and frames that wrap and flow text, and tables that break across pages and repeat their header rows.
- Bar charts, donut charts, XY charts and calendars.
- Barcodes: Code 128, Code 39, UPC-A, EAN-13, QR codes, Data Matrix and PDF417.
- PNG, JPEG and BMP images, and SVG drawn as vector graphics.
- Links, bookmarks, annotations, attached files, layers and forms.
- PDF/UA for accessibility, and PDF/A-1, 2 and 3 for archiving, each with one setting.
- AES-256 encryption with passwords and permissions.
- Reading existing PDFs: merging, splitting and adding to their pages.

## How this booklet is organized

The first chapters show how to install PDFjet, what a PDFjet program looks like, and how to use the library efficiently. The chapters after them go through the API a part at a time: documents and pages, fonts, text, tables, graphics, images, charts, barcodes, links and annotations, forms, and existing PDFs. Each feature comes with the smallest piece of code that shows it, and says which classes and methods to look at.

The code is not typed into this booklet. It is read from the snippet programs in the booklet/snippets folder of the repository, one for each language, which are built and run to check that every snippet works and draws the same in the four languages.

A snippet draws with two things it is given: pdf, the PDF it draws in, and font, IBM Plex Sans at 12 points, created as in Hello, World below. The snippets that make a document of their own, such as an encrypted one, create their own PDF. The snippets read their fonts, images and data from the fonts, images and data folders of the repository, as the examples do. The examples folder has 54 longer programs, which show more of each feature together.

This booklet was made with PDFjet, by booklet/Booklet.java in the repository. It is a PDF/UA document, with bookmarks and a linked table of contents.

# Getting started

## Installing PDFjet

@lang java
Build PDFjet.jar with ./build-java.sh from the root of the repository, which also builds and runs the examples, and put the jar on the class path of your program. PDFjet runs on Java 8 and later.
@end
@lang csharp
Build bin/release/net8.0/PDFjet.dll with ./build-dotnet.sh from the root of the repository, which also builds and runs the examples, and add a reference to it in your project. PDFjet runs on .NET 8 and later.
@end
@lang go
Add the module to your program with the go command. The module path carries the major version, as Go requires from version 2 on.

    go get github.com/edragoev1/pdfjet/v9@latest

The Go module has the source of the library and the examples only. Copy the fonts folder of the repository next to your program; the core fonts need no files.
@end
@lang swift
Add PDFjet to the Package.swift of your package, and the PDFjet product to the target that uses it:

    dependencies: [
        .package(url: "https://github.com/edragoev1/pdfjet.git", from: "9.0.0"),
    ],
    targets: [
        .executableTarget(name: "App", dependencies: [
            .product(name: "PDFjet", package: "pdfjet"),
        ]),
    ]
@end

The fonts that come with PDFjet, such as IBMPlexSans.Regular, are paths relative to the working folder, so a program that uses them runs in a folder that has the fonts folder of the repository.

## Hello, World

This program writes hello.pdf with one line of text in English, Greek and Bulgarian, in IBM Plex Sans at 18 points.

@code java
import com.pdfjet.*;
import com.pdfjet.fonts.*;
import java.io.*;

public class Hello {
    public static void main(String[] args) throws Exception {
        PDF pdf = new PDF(new BufferedOutputStream(new FileOutputStream("hello.pdf")));
        Font font = new Font(pdf, IBMPlexSans.Regular).setSize(18f);
        Page page = new Page(pdf, Letter.PORTRAIT);
        new TextLine(font, "Hello, World! Γειά σου, κόσμε! Здравей, свят!").setLocation(50f, 100f).drawOn(page);
        pdf.complete();
    }
}
@end

## The shape of a PDFjet program

Every PDFjet program has the same four steps. It creates a PDF on an output stream, adds the fonts and images it needs to the PDF, creates pages, and draws on each page. When it is done, it completes the PDF, which writes what is left and closes the stream.

Positions are in points, 72 to an inch, from the top left corner of the page, with y growing down the page, as a page is read. Every component, a text line, a text block, a table, an image, a chart or a barcode, has a location that setLocation sets, and a drawOn method that draws it on a page. drawOn returns the x and y of the bottom right corner of what it drew, so the next component can start below it.

A font can be one of the fonts that come with PDFjet, such as IBMPlexSans.Regular, any OpenType or TrueType file, or one of the 14 core fonts, such as Helvetica, which every PDF viewer has and which is not embedded. The embedded fonts draw any character they have, and are the ones to use for accessible and archival documents. The core fonts make the smallest documents, but draw only the characters of Windows Latin 1.

For an accessible document, set the compliance to PDF/UA-1 and give the document a title, before anything else. PDFjet then tags every text line, text block, table cell and image, and marks lines, shapes and backgrounds as decoration, which screen readers skip. For an archival document, set one of the PDF/A levels instead.

# Working efficiently

PDFjet is fast by design, and a few habits keep it that way.

- Create each font once and use it everywhere. A Font object embeds its font in the PDF once, however many pages use it, and a text line can draw in another size of the same font with setFontSize, without a second font.
- Use the .stream fonts that come with PDFjet, such as IBMPlexSans.Regular. They are the same fonts, compressed once ahead of time, so they load faster than the .otf and .ttf files and are written to the PDF as they are.
- Add an image to the PDF once and draw it on as many pages as you like. The image data is written once.
- Write to a buffered stream, and let PDFjet write each page out as the next one starts. A document of thousands of pages needs no more memory than one page.
- For a table of tens of thousands of rows, use BigTable, which writes the rows as it reads them, rather than Table, which holds every cell until it is drawn. Example 43 writes 124,716 rows of a CSV file this way.
- Measure before you draw. drawOn returns where a component ends, and a text block drawn on no page, with drawOn(null), returns its size without drawing it, so a layout can decide where things go before it draws them.
- Leave the compliance, PDF/UA or PDF/A, on from the start. Tagging costs little, and the document is accessible without a second pass.


# Documents and pages

A PDF object is the document: it writes to an output stream, holds the fonts and images, and is completed at the end. A Page is one page of it, of a PageSize, drawn on from the top left corner.

@snippet document-info The document information
The title, the author, the subject and the keywords are what a PDF viewer shows in the properties of the document. setLanguage sets the language of its text, which screen readers need, and setTitle is required for PDF/UA.

@snippet page-sizes Page sizes
Letter, Legal, A3, A4, A5, B5 and the other page size classes each have a PORTRAIT and a LANDSCAPE size. A PageSize of any width and height, in points, makes a page of another size, and getWidth and getHeight tell a page's size.

@snippet page-numbers Detached pages and page numbers
A page created with Page.DETACHED is not added to the PDF when it is created, so it can be drawn on first and added later, with addPages. Here the pages are kept in a list until all are drawn, when the list knows the number of pages for "Page X of N". addFooter draws a line of text centered at the foot of the page, its baseline the offset above the bottom, and addHeader at its head. Detached pages also let a program add pages in another order than it draws them, such as a table of contents first.

@snippet watermark A watermark
addWatermark draws a text across the page, from its bottom left corner to its top right corner, in light gray, as decoration. Draw it first, so that the text of the page is drawn over it.

@snippet accessible-document An accessible document
A PDF with the compliance PDF_UA_1 is a PDF/UA document: PDFjet tags every text line, text block, table cell and image, so that screen readers read the document in order, and marks lines, shapes and backgrounds as decoration. The document needs a title, and every image a description, set with setAltDescription. setStructureType makes a text a heading, H1 to H6, which readers use to move through the document.

@snippet archival-document An archival document
The compliance levels PDF_A_1A to PDF_A_3B make a PDF/A document, for long-term archiving: every font is embedded, and the document carries what it needs to look the same in any viewer. The A levels are tagged as PDF/UA is; the B levels only keep the look. PDF/A-3 can have files attached.

# Fonts

A Font is created once for a PDF and used by any number of text lines, blocks and tables. Its size is set with setSize, and a text line can draw in another size of the same font with setFontSize.

@snippet fonts The fonts that come with PDFjet
The classes of the com.pdfjet.fonts package, such as IBMPlexSans, SourceSerif4, JetBrainsMono and NotoSans, name the font files that come with PDFjet: IBM Plex in its Sans, Serif, Mono and Math families and in Arabic, Hebrew, Thai, Japanese, Korean and Chinese; Source Serif 4; JetBrains Mono; and Noto Sans. They are .stream files, the fonts compressed once ahead of time, so they load fast, and PDFjet embeds only the characters a document uses.

@snippet font-files Fonts from files
Any OpenType or TrueType font file is a font for PDFjet: pass its path, or an input stream of it, to the Font constructor.

@snippet core-fonts The core fonts
The 14 core fonts of CoreFont, Helvetica, Times, Courier with their bold and italic, Symbol and ZapfDingbats, are in every PDF viewer and are not embedded, so they make the smallest documents. They draw only the characters of Windows Latin 1, and PDF/UA and PDF/A do not allow them. setKernPairs(true) moves the letters of kerning pairs, such as A and V, closer together.

@snippet cjk-fonts Chinese, Japanese and Korean fonts that are not embedded
The CJKFont fonts are the Chinese, Japanese and Korean fonts that PDF viewers supply, so the document carries no font program at all. They are the smallest way to write CJK text, when the document does not have to be PDF/UA or PDF/A; the IBM Plex fonts of each language are the ones to embed.

@snippet fallback-font A fallback font
A fallback font draws the characters that the font does not have, such as Japanese in a Latin font, so that one line of text can mix scripts. Text lines, text blocks and table cells have setFallbackFont.

@snippet font-metrics Measuring text
stringWidth returns the width of a text in the font at its size, which places text by its end, as here, or centers it. getBodyHeight is the height of a line of the font, from its ascent to its descent, and getAscent and getDescent are the parts above and below the baseline.

# Text

A TextLine is a line of text in one font and color. A TextBlock wraps a text at a width. A Paragraph is a text of several text lines, in different fonts and colors, which a TextFrame or a TextColumn wraps and flows.

@snippet text-line A line of text
The location of a text line is the start of its baseline. It has a size, a color, underline and strikeout, a rotation in degrees, and a vertical offset for raised or lowered text. drawOn returns the x and the y of where the line ends, so that the next text can follow it.

@snippet text-block A block of text
A text block wraps its text at its width, and starts a new paragraph at an empty line. It has line spacing, padding, a border, a background, rounded corners, and left, right or centered text. drawOn returns its bottom right corner; drawOn(null) returns it without drawing, to measure the block before placing it.

@snippet highlighted-words Highlighted words
setHighlightColors draws the words of a map in their colors, in a text line, a text block or a paragraph: keywords, names, or search results.

@snippet paragraphs Paragraphs of mixed styles
A paragraph is a list of text lines, each with its font, size and color, which are wrapped together as one text, with a space between them. A TextFrame draws a list of paragraphs at a location and width, each aligned left, right, centered or justified, with a gap between them.

@snippet lists Numbered and bulleted lists
setListLabel gives a paragraph a label, a number or a bullet, which is drawn to the left of it, the text indented by the width given. In a PDF/UA document the labeled paragraphs are tagged as a list.

@snippet text-column A text column
A TextColumn draws its paragraphs one under the other, aligned or justified, with space between them. It fits a short text at a known place, such as a column of a page or a table cell.

@snippet text-frame-pages Text that flows onto new pages
drawOn(pdf, pages, pageSize) draws the text on as many new pages as it needs, a whole book at once, as a table does. The pages are detached and added to the list, so that page numbers can be drawn on them before they are added to the PDF with addPages. The frame keeps the margins of its location at the bottom of the page too.

@snippet text-frame-columns Text that flows through columns
A text frame with a height draws what fits in it and keeps the rest for the next drawOn, until hasMoreText is false. Moving the frame between the calls flows the text through the columns of a page and on to the next page.

@snippet markup Inline markup
A Markup reads the inline markup of Markdown, **bold**, *italic*, ***bold italic***, `code` and [links](url), and makes paragraphs of text lines in the fonts given for each. A word keeps the punctuation after it in another style, with no space between them, and a mark with no match is text. paragraphs splits a text into paragraphs at its empty lines. Headings, lists and the other blocks of Markdown are not read.

@snippet markdown Markdown
A Markdown draws a Markdown text on as many pages as it needs: its headings, paragraphs with the inline markup of Markup, bullet and numbered lists that nest, block quotes, fenced code, thematic breaks, tables and images, each tagged for PDF/UA. A heading keeps a line of the text after it on its page, and a table, a list or code goes on onto the next page. Images are read only from the directory setImageDirectory names; HTML is drawn as the text it is. Please see Example_54.

@snippet right-to-left Right to left text
A text block with setRightToLeft(true) draws Hebrew, Arabic and Persian text from right to left, with the Arabic letters shaped. For a single text line, Bidi.reorderVisually puts the characters in the order they are drawn in. setLanguage tells screen readers the language of the text.

@snippet formulas Chemical formulas
A CompositeTextLine draws one line out of parts on the baseline, above it and below it. addFormula reads a chemical formula: the digits after an element are subscripts, and what follows a circumflex is a superscript, such as the charge of an ion.

# Tables

A Table is a list of rows, each a list of Cells. It measures its columns and rows, breaks across pages, and repeats its header rows on every page. In a PDF/UA document its cells are tagged as a table, the header rows as headers.

@snippet table A table
setTableData takes the rows and the number of header rows. autoAdjustColumnWidths makes each column as wide as its text needs, and rightAlignNumbers aligns the columns of numbers to the right.

@snippet table-pages A table over pages
drawOn(pdf, pages, pageSize) draws the table on as many new pages as it needs, with the header rows at the top of each, and returns them in the list, detached, to be added to the PDF. The bottom margin is where each page stops. The constructor Table(f1, f2, fileName) reads the rows from a CSV file instead.

@snippet cells Cells that span columns, colors and borders
A cell has its font, text color, background color, borders, padding, and text aligned left, right or centered, top, center or bottom. setColSpan makes it span columns, and setRowSpan rows; the row keeps a cell for each column it covers, which is not drawn.

@snippet cell-content Images, barcodes and text blocks in cells
A cell can hold an image, a barcode, a text block, a text column or any other drawable instead of its text. The row grows to the height of what it holds.

@snippet table-style The width and the style of a table
setColumnWidthsInPercent and setWidth share the width of the table among its columns. setHeaderRowStyle gives the header rows a font, a text color and a background at once, and setAlternateRowColor colors every other row of the body.

@snippet table-sums Page totals and totals carried forward
setNumberOfFooterRows makes the last rows footer rows, drawn at the end of the table on every page. setPageSum makes a cell of a footer row the sum of its column on the page, and setRunningSum the sum of all the rows up to the end of the page, the total carried forward. setBroughtForwardSum puts the total of the pages before in a header row.

@snippet big-table A table of any number of rows
A BigTable writes each row as it reads it, and each page as it is full, so it needs little memory however many rows there are. It reads a CSV file, or rows from an iterable, and pages itself. The order of the calls matters: the number of columns, the data, the location and the margin, then complete.

# Graphics

Components draw shapes with setLocation and drawOn, as text does. A page also draws with a pen and a brush, a path at a time, as PDF itself does.

@snippet shapes Lines, rectangles, points, ellipses and arcs
A Line has its end points, a width and a dash pattern. A Rect has a fill, a border and rounded corners. A Point draws a marker of a Shape: a circle, a box, a star, an arrow and others. An Ellipse and an Arc have their radii, and an arc its start angle and sweep.

@snippet paths Paths and curves
A Path joins its points with lines, and with Bezier curves where points are control points, marked with Point.CONTROL_POINT_C. setClosed closes the path and setFillShape fills it.

@snippet page-graphics Drawing on a page
A page draws as PDF does: setPenColor, setPenWidth and setStrokeDashPattern for lines, setBrushColor for fills, then moveTo, lineTo and bezierCurveTo to make a path, and strokePath or fillPath to draw it. drawLine, drawRect, fillRect and drawString draw in one call.

@snippet transparency Transparency
A GraphicsState sets the alpha of the fills and the strokes that follow it, until the graphics state is restored. saveGraphicsState and restoreGraphicsState keep it to the shapes between them.

@snippet containers Containers
A Container holds components at locations of its own, and draws them together at its location, turned by its rotation and scaled.

@snippet stamps Stamps
A Stamp is a drawing written to the PDF once, with its fonts, and drawn at any location, rotation and scale, as many times as needed, such as a logo or a mark on every page.

# Images

@snippet images JPEG, PNG and BMP images
An Image reads a JPEG, a PNG or a BMP file, and is written to the PDF once, however many times it is drawn. scaleBy, resizeWidth and resizeHeight set the size it is drawn at, and setRotation turns it. Every PNG color type and bit depth is read, with transparency, and CMYK JPEGs too. setAltDescription describes the image for screen readers.

@snippet svg-images SVG images
An SVGImage reads the paths of an SVG file and draws them as vector graphics, which stay sharp at any size: icons, logos and maps.

# Charts

Each chart takes two fonts: one for its title, one for its labels. setAltDescription describes what it shows for screen readers.

@snippet line-chart Line and XY charts
A Chart draws its Series of points on two axes, as markers, lines, or both: setDrawPath joins the points. The axes are scaled to the points, or set with setXAxisMinMax and setYAxisMinMax.

@snippet bar-chart Bar charts
A BarChart draws a series of values for each category, side by side, or stacked with setStacked, vertical or horizontal with setHorizontal, with a legend and the values on the bars if asked.

@snippet donut-chart Donut and pie charts
A DonutChart draws its slices with their labels and shares. An inner radius of 0 makes a pie chart.

@snippet calendar A calendar
A CalendarMonth draws a month of a year, with its weeks starting on the day setFirstDayOfWeek sets.

# Barcodes

A barcode is drawn at its location with a module length, the width of its narrowest bar or square, in points.

@snippet barcodes Linear barcodes
A Barcode draws Code 128, Code 39, UPC-A and EAN-13, and adds the check digit of UPC-A and EAN-13. With a font it draws its text under the bars. setDirection draws it from top to bottom or from bottom to top.

@snippet qr-code QR codes
A QRCode holds text in UTF-8, such as a web address, at one of four error correction levels, L, M, Q and H: a higher level lets a scanner read a damaged code and holds less data.

@snippet data-matrix Data Matrix
A DataMatrix symbol holds text in UTF-8, in a square symbol or, with DataMatrix.RECTANGLE, a rectangular one.

@snippet pdf417 PDF417
A PDF417 barcode is stacked rows of bars that hold much more data than a linear barcode, as on boarding passes and identity cards.

# Links, bookmarks, annotations and layers

@snippet web-links Links to web pages
setURIAction makes a text line, a text block, a cell, a rectangle, an image or a point a link to a web address.

@snippet internal-links Links inside the document
setDestination names the place of a text line, and setGoToAction makes another component a link to it. page.addDestination names any place of a page.

@snippet bookmarks Bookmarks
A Bookmark is the outline that PDF viewers show beside the pages. addBookmark adds a Title under a bookmark, which goes to the title's place on its page, and returns the new bookmark, to add bookmarks under it in turn. autoNumber numbers them from their place, 1, 1.1, 1.2 and so on.

@snippet attachments Attached files
An EmbeddedFile is a file written into the PDF, and a FileAttachment shows it on a page as an icon, a push pin or a paperclip, which opens or saves the file.

@snippet notes Notes
A TextAnnotation is a note on the page, shown as an icon that opens its text. The PolygonAnnotation, SquareAnnotation and CircleAnnotation mark areas of the page, with a note.

@snippet layers Layers
An OptionalContentGroup is a layer that PDF viewers list and can show or hide. Components added to it are drawn in it, and it can be visible or not, and printed or not.

# Forms

@snippet check-boxes Check boxes and radio buttons
A CheckBox and a RadioButton draw a box or a circle with a label, checked or selected, for forms that are printed and filled in by hand or read as they are.

@snippet form-fields Forms of labeled fields
A Form draws a list of Fields, each a label over a value, in rows and columns: a field at x 0 starts a new row, and a field with an empty label goes on with the value above it.

# Existing PDFs and security

PDFjet reads existing PDFs too: read returns the objects of a document, which can be merged into a new PDF, split, or drawn on. And it encrypts documents with AES-256.

@snippet merge Merging PDFs
merge adds the pages of a document that read returns to the PDF, with their content, fonts, images, annotations and links. Pages drawn with PDFjet can come before and after them.

@snippet split Splitting a PDF
merge takes the numbers of the pages to add, from 1, in any order, so a document can be split into parts, a page each, or have its pages reordered.

@snippet existing-pages Drawing on the pages of an existing PDF
A Page made from a page object of an existing document draws over what the page has. addResource adds a font or an image to the document the page is in, and complete finishes the page; addObjects writes the objects into the new PDF.

@snippet encryption Encryption
An Encryption with AES-256 protects the document with a user password, which opens it, and an owner password, which changes what the user may do: print, copy, change or fill in the document. The Permissions grant what the user may do.
