# Test fonts

IBM Plex Sans Regular and Italic with CFF outlines keyed by glyph names
(`.otf`), as most `.otf` fonts are, for the tests of the subsets of such
fonts. PDFjet carries the `.ttf` of these fonts in `resources/fonts`, and
its CJK fonts as `.otf` keyed by CIDs; these two are test data only, under
the SIL Open Font License 1.1, in `IBMPlexSans-license.txt`.
